# 指令记录器

深色主题的桌面命令记录工具。把常用指令、用途说明和软件环境记在一起，需要时左键点击指令即可复制。

## 功能

- **用途说明突出展示**：每张卡片的右侧固定显示用途说明，不再挤压在标题行里；长说明可滚动查看全文。窄窗口下会自动改为指令在上、用途在下。
- **双列紧凑列表**：每行显示两张卡片，卡片采用“环境 + 指令/用途”的结构，尽量在一屏展示更多指令。
- **点击即复制**：左键点击任意指令卡片即可复制完整指令，并显示复制提示。
- **软件环境分类**：每条指令可填写一个软件环境（如 Git Bash、Docker、VS Code），左侧会自动汇总并支持筛选。
- **手动排序**：选择“手动排序”后拖动卡片左侧手柄调整指令顺序，方向键也可移动；左侧环境可直接拖动排序，或按 `Alt + ↑/↓` 调整。排序结果会保存。
- **收藏与其他排序**：星标收藏，也可按“收藏优先 / 最近添加 / 最早添加 / 名称 A–Z”排序，排序偏好会记住。
- **搜索**：同时搜索指令、用途和环境。
- **导入导出**：可将全部指令（含用途、收藏状态、环境及环境顺序）导出为 JSON 备份，便于存档或分享；导入时支持“合并导入”和“替换全部”，合并会跳过完全重复的指令。
- **暗色自适应界面**：窗口可自由缩放，窄窗口下卡片和侧栏会自动重排。
- **本地存储**：数据保存在本机 `%APPDATA%\指令记录器\commands.json`，并在每次保存时生成 `.bak` 备份。旧版本保存的中文译文会在用途为空时自动迁移为用途说明。
- **删除撤销**：删除指令后可在提示条中撤销。

## 使用

1. 点击右上角“新建指令”（`Ctrl + N`）。
2. 输入指令，填写它解决什么问题和常用软件环境，按需勾选收藏，然后保存。
3. 点击指令卡片复制；使用左侧环境筛选或右上角排序整理指令。
4. 在“手动排序”模式下拖动卡片左侧的六点手柄排序；左侧环境条目也可直接拖动，或聚焦后按 `Alt + ↑/↓` 调整。
5. 点击“导出”保存 JSON 备份，点击“导入”选择备份文件；合并导入只追加新指令，替换导入会覆盖当前指令库（需要再次点击确认）。
6. 快捷键：`Ctrl + N` 新建、`Ctrl + F` 或 `/` 聚焦搜索、`Esc` 关闭编辑框。

## 开发与构建

```bash
npm install
npm start          # 本地运行
npm test           # Node 单元测试
npm run pack       # 生成未打包目录
npm run dist       # 生成 Windows 安装包和便携版
```

构建产物位于 `release/`：

- `指令记录器-安装包-1.3.1.exe`：安装版（NSIS，可选择安装目录，创建桌面快捷方式）
- `指令记录器-便携版-1.3.1.exe`：免安装单文件版（运行时会解压到临时目录，数据仍保存在用户目录）
- `win-unpacked/指令记录器.exe`：解包后的程序目录，可直接运行

安装包和程序未进行代码签名，首次运行时 Windows SmartScreen 可能提示“已保护你的电脑”，选择“更多信息 → 仍要运行”即可。应用数据与设置只保存在本机。

如果打包时需要重新下载 Electron/NSIS 等资源，而默认源连接较慢，可以使用国内镜像后重试：

```bash
ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/ \
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ \
npm run dist
```

图标源脚本：`build/make-icon.ps1`。
