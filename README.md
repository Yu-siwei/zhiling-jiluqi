# 指令记录器

深色主题的桌面命令记录工具。把常用指令、中文翻译、用途和软件环境记在一起，需要时左键点击指令即可复制。

## 功能

- **英文自动翻译**：输入英文指令后自动获取中文译文，译文可手动修改；网络不可用或接口没有返回有效中文时，会尝试用内置常见命令词典生成中文释义。
- **双列紧凑列表**：每行显示两张卡片，卡片采用“环境/用途 + 指令/译文”的紧凑结构；窄窗口下卡片内部自动改为上下排列，尽量在一屏展示更多指令。
- **点击即复制**：左键点击任意指令卡片即可复制完整指令，并显示复制提示。
- **软件环境分类**：每条指令可填写一个软件环境（如 Git Bash、Docker、VS Code），左侧会自动汇总并支持筛选。
- **手动排序**：选择“手动排序”后拖动卡片左侧手柄调整指令顺序，方向键也可移动；左侧环境可直接拖动排序，或按 `Alt + ↑/↓` 调整。排序结果会保存。
- **收藏与其他排序**：星标收藏，也可按“收藏优先 / 最近添加 / 最早添加 / 名称 A–Z”排序，排序偏好会记住。
- **搜索**：同时搜索指令、译文、用途和环境。
- **导入导出**：可将全部指令（含译文、用途、收藏状态、环境及环境顺序）导出为 JSON 备份，便于存档或分享；导入时支持“合并导入”和“替换全部”，合并会跳过完全重复的指令。
- **暗色自适应界面**：窗口可自由缩放，窄窗口下卡片和侧栏会自动重排。
- **本地存储**：数据保存在本机 `%APPDATA%\指令记录器\commands.json`，并在每次保存时生成 `.bak` 备份。
- **删除撤销**：删除指令后可在提示条中撤销。

## 使用

1. 点击右上角“新建指令”（`Ctrl + N`）。
2. 输入英文指令，稍等片刻，右侧会自动出现中文翻译；也可直接修改译文。
3. 填写用途、软件环境，按需勾选收藏，然后保存。
4. 点击指令卡片复制；使用左侧环境筛选或右上角排序整理指令。
5. 在“手动排序”模式下拖动卡片左侧的六点手柄排序；左侧环境条目也可直接拖动，或聚焦后按 `Alt + ↑/↓` 调整。
6. 点击“导出”保存 JSON 备份，点击“导入”选择备份文件；合并导入只追加新指令，替换导入会覆盖当前指令库（需要再次点击确认）。
7. 快捷键：`Ctrl + N` 新建、`Ctrl + F` 或 `/` 聚焦搜索、`Esc` 关闭编辑框。

## 翻译说明

自动翻译会通过在线服务（MyMemory 免费接口）把英文指令文本发送出去；如果指令中包含敏感信息，请在保存前删除或手动关闭/覆盖译文。应用自身不会上传本地指令库。

## 开发与构建

```bash
npm install
npm start          # 本地运行
npm test           # Node 单元测试
npm run pack       # 生成未打包目录
npm run dist       # 生成 Windows 安装包和便携版
```

构建产物位于 `release/`：

- `指令记录器-安装包-1.2.0.exe`：安装版（NSIS，可选择安装目录，创建桌面快捷方式）
- `指令记录器-便携版-1.2.0.exe`：免安装单文件版（运行时会解压到临时目录，数据仍保存在用户目录）
- `win-unpacked/指令记录器.exe`：解包后的程序目录，可直接运行

安装包和程序未进行代码签名，首次运行时 Windows SmartScreen 可能提示“已保护你的电脑”，选择“更多信息 → 仍要运行”即可。应用数据与设置不会被上传；只有自动翻译时会把英文指令文本发送给在线翻译服务。

如果打包时需要重新下载 Electron/NSIS 等资源，而默认源连接较慢，可以使用国内镜像后重试：

```bash
ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/ \
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ \
npm run dist
```

图标源脚本：`build/make-icon.ps1`。
